## 0. 服务器先读：当前决策

**保留实验结果，收窄机制结论。当前证据支持停止优先投入已失败的具体缩放/线性编辑配置，不支持宣判在线 readout、上下文化或冻结 cache 路线整体失败。**

下一步顺序：

1. 修正统计口径及报告中的过强结论。
2. 补齐同样本、同评分口径的 raw–memory 对照，确认真正剩余的性能差距。
3. 做 K=2 gold 文档与逐跳诊断，区分事实读取、桥接连接、组合及干扰问题。
4. 若仍研究上下文化，再做功能性阻断实验。
5. 只有失败定位明确后才启动新结构或压缩器训练。

**暂缓**：以“均值大就是容量浪费”为依据启动白化/去中心化压缩器；继续盲扫 output_scale；没有新失败证据的 readout 结构搜索。

**保留 QuRO 的核心约束**：文档表示离线计算、query 无关、可跨查询复用。是否继续使用原 PISCO cache 是实验选择，不是不可修改的原则；但换 cache 必须有失败定位支持。

## 1. 当前实验支持什么

| 观察 | 可支持的结论 | 不可直接推出 |
| --- | --- | --- |
| SeleCom 式 prompt 下 memory 比 raw 更难遵循冲突指令 | 输入表示影响行为，效应依赖 prompt/interface | 该现象是正常 QA 性能差距的主因 |
| memory 没有在全层全头平均注意力上压倒 instruction | 不支持普遍注意力塌缩的简单解释 | 注意力路径与失败完全无关 |
| P₁=0.5990，Pa10=0.5845，Pa05=0.5880 | 当前训练协议下两种缩放没有增益 | 所有上下文化方案无用 |
| 去均值/去主方向损害原 decoder 的重建 | 推理时编辑破坏当前可读性 | 信息已消失，或所有线性方法都不可分离 |
| 域内 decoder LoRA：0.4850→0.5990 substring | 域内训练是目前明确有效的干预 | 全部增益来自证据读取，或已经补齐压缩代价 |
| 初步 bridge 差距大于 comparison | 值得按问题结构继续定位 | 已证明跨文档组合失败、排除了信息损失 |

Stage C 的数值负结果可以保留。单 seed 的配对 CI 衡量给定训练结果下的样本不确定性，不覆盖训练 seed 方差。

### 1.1 不可行性与非必要性分开

本轮主要研究压缩表示的消费方式和指令遵循，不足以完整回答 SeleCom 的“全量内容不必要”。

- 单次 query 可能只需要少量证据。
- 同一文档面向不同 query 的可复用缓存，可能需要保留更广泛信息。
- 两者可以同时成立。

不要用冲突指令实验替代 query-specific sufficiency（针对某个 query 的证据充分性）实验。后续若回到 QuRO 主张，应在固定文档、多问题场景分别评估离线信息覆盖与在线读取预算。

## 2. 必须修正的统计与推理

### W1：逐层余弦连乘不是首尾余弦，也不是一般下界

报告将：

`product_l cos(h[l+1], h[l])`

解释成最终状态与输入 embedding 的对齐程度，不能成立。

反例：同向连续旋转两次 45°，相邻余弦乘积为 0.5，首尾余弦为 0；第二次反向转回，乘积仍为 0.5，首尾余弦为 1。

**行动：**

- 撤回“文本首尾 cos≈0.014、memory 首尾 cos≈0.67”的解释。
- 直接逐 token 计算 `cos(h[l], h[0])`，再按 document/sample 聚合。
- 原乘积若保留，只能作为自定义逐层稳定性统计，不标为首尾旋转或下界。
- 报告逐层分布与样本间变异，避免仅用全局均值。

### W2：主方向能量占比的分母错误

`estimate_latent_statistics()` 只保存 `singular[:rank]`（默认 rank=32），
`LatentStatistics.summary()` 用这些保留值的平方和作分母。

所以“第一方向 47.5%、前八方向 72.5%”当前是相对保留谱的比例，不能写成占全部 latent 二阶矩能量的比例。

**行动：**

- 在采样矩阵 `flat` 上保存总能量 `flat.square().sum()`。
- 总二阶矩占比用 `sum(top_k_singular_values**2) / total_energy`。
- 区分未中心化二阶矩与中心化协方差，不把两者统称 PCA 方差解释率。
- 重新生成统计，并记录抽样、随机化 SVD 的随机种子与近似口径。
- 原能量占比及据此产生的容量结论标记为待更正。

**均值范数比也不等于容量占比。** `56.4/104≈54%` 不是“54% 信息容量被常量占用”。大均值可与丰富的小幅信息变化共存。

### W3：最后一步 hidden-state 差分可能混入 final RMSNorm

当前 collector 对 `output.hidden_states` 的相邻项直接做差。末项是否包含 final norm 取决于实际 Transformers 版本的返回口径，需核对运行环境。

**行动：**

- 记录运行时 Transformers 版本。
- 用 block hooks 捕获每个 block 的真实输入/输出；final RMSNorm 单独统计。
- 不把末项暴涨直接归因于最后一个 block 的“加工”。
- 修正前不使用该末项支持机制论断。

### W4：相对更新小不等于只读，更不等于不参与计算

`||Δh||/||h||` 受分母影响。小更新可能落在决定答案的重要方向；各层 K/V 投影矩阵也不同，即便残差变化小，各层提供的 K/V 仍不同。

后续 query/answer 位置能够跨层读取并组合多个 memory。文档位置自身是否大幅演化，与整个系统能否跨文档推理不是同一件事。

**行动：**

- 将“只读 K/V”“对各层免疫”“它本身不参与计算”改为“残差相对变化较小，功能意义待干预验证”。
- 不用文本 token 的 0.55 作为 latent 必须达到的健康标准。
- 不把任意设置的 0.3 阈值等同于有效上下文化。

### W5：后续指令不能影响前面的 memory 是因果掩码的预期结果

当前序列将文档置于 instruction/query 前。仅改变后续 reconstruct/conflict 指令，前面文档位置看不到该改变，raw 也应如此。

**行动：**

- 撤回“不同指令下 document 统计一致，因此证明 latent 结构性不参与计算”的推论。
- 在真实 K=10 QA prompt 上验证诊断，不直接将 Level A 短文档/单文档统计外推到多文档组合机制。
- 若讨论 query-conditioned computation，明确发生在外部 readout、后续 query/answer 位置，还是改变了输入顺序；不要忽略因果可见性。

### W6：缩放不是只动写路径的纯净机制干预

正比例缩放下 RMSNorm 的尺度不变性仅在忽略 epsilon 时近似成立。即便初层归一化方向近似不变，残差更新后：

`h1(alpha) = alpha*z + u`

一般不再与 `h1(1)=z+u` 共线，后续归一化方向和读取路径都会改变。

**行动：**

- 撤回“读路径严格不变、只动写路径”。
- 撤回“低秩 LoRA 不可能产生某倍数的位置相关更新”这类无证明的能力上限判断。
- 相对更新降低要拆成更新绝对范数与残差范数分别检查，不拟人化为“模型拒绝组合”。
- Stage C 未实现预定机制状态且 QA 无增益，说明当前干预失败；不能据此宣称上下文化假设被干净证伪。
- 零训练与训练后的掉幅若来自不同 n/harness，不直接相减当成受控的恢复幅度。

### W7：可读性下降不等于信息消失；有限编辑失败不等于线性不可分

固定均值的去中心化：

`z' = z - mu_global`

在均值已知时可逆，本身不丢信息。原 decoder 的重建下降，说明原接口不适配新坐标，不能证明信息被删除。主方向投影可能丢信息，但仍需区分信息损失与解码失配。

**行动：**

- 将“线性不可分”“任何线性操作都会带走文档信息”改为“测试过的无监督编辑在固定 decoder 下未达到双目标”。
- 不将若干实验点称为已证明的最优权衡边界。
- `mu_global` 单独导致压制可保留为现象，但撤回“81% 压制由它承载”的因果贡献分解；非线性交互与 none 的输入结构差异未被控制。
- 若后续研究该方向，应比较编辑后适配与同预算原表示适配，且将其作为新假设，不以当前结果声称必然成功。

### W8：bridge/comparison 分层不能单独定位组合瓶颈

comparison 也需要整合事实，两类题还存在实体显式程度、答案类型、稀有事实精度等差别。comparison 表现好不能排除 bridge 信息损失。

**行动：**

- 保留“缺口在该小样本中主要出现在 bridge”。
- 撤回“因此不是压缩丢信息”“comparison 压缩免费甚至更好”的普遍结论。
- n=39 的 comparison 结果只是初步线索，需在统一更大样本下复测。
- 不把重建中桥接实体未出现等同于未编码，也不把实体出现等同于关系完整保留。

### W9：平均注意力没有解释力，不等于注意力路径无因果作用

全层全头聚合可能掩盖关键 head、层、目标步。随机化方向还改变了内容和 value，不是对注意力份额的单变量干预。当前 `v_contrib` 是 head 内 value 加权和范数，尚不等于经过输出投影后的净残差贡献或任务贡献。

**行动：**

- 将“失败不经过注意力通道”“所有注意力 gate 都无意义”收窄为“不支持全局 dominance 的简单解释，当前无证据优先开发通用校准模块”。
- 不因该收窄立即扩大 head 搜索；仅在具体失败样本和明确假设下做定位。
- 不把不显著相关或 CI 含 0 写成严格等价/没有效应。

## 3. 之前方案失效的合理解释：保持候选，不强行统一

| 方案 | 已知结果 | 候选解释，不是定论 |
| --- | --- | --- |
| 注意力校准方向 | 缺少普遍 dominance 的证据 | 最初针对的瓶颈可能不存在，或聚合指标没测到关键路径 |
| output_scale | 零训练损伤，适配后未超过 P₁ | 训练主要恢复接口兼容性，未改善所需事实/组合能力 |
| 去均值/主方向 | 原 decoder 重建下降 | 输入分布变化；投影还可能删除有用信息 |
| A/C 等预算读出 | 当前配置没有超过强 P baseline | 二次压缩损失、输出接口扰动、预算或训练信号问题 |
| R/RQ 残差式读出 | 当前配置无稳定边际 | decoder 已完成类似读取；监督不足；优化/表示问题等仍需区分 |

共同教训：**不能先把内部统计当作缺陷，再以优化该统计替代 QA 失败定位。**

暂停无新证据的结构尝试，但不要从若干配置的零结果推出整个方法类别不可能有效。历史各臂必须按输入预算、训练协议、query 路径分别比较，不能机械计成“四次失败＝cache 已被证明有根本问题”。

## 4. 下一轮执行计划

### P0-A：先修统计和报告，不重跑所有训练

交付：

- 更正能量占比计算，重算对应摘要。
- 直接首尾余弦与 block 前后 hook 统计。
- 所有受影响的原结论保留更正记录，不覆盖历史结果造成不可追溯。
- 将测量、推断、未验证机制分列。
- 在原报告显著位置链接本警示及后续更正。

已有结果足够保留“当前缩放不增益”的决策，不必为了更正文字重跑全部训练。

### P0-B：统一 raw–memory 差距

同样本、同文档内容、同截断口径、同生成参数与评分：

| decoder | raw | memory | 问题 |
| --- | --- | --- | --- |
| 发布 PISCO decoder | 评测 | 已有但核对口径 | 冻结系统表示差异 |
| memory QA 训练后的 P₁ | 评测 | 已有 | 同一已训练 decoder 换表示 |
| 相同数据/训练预算的 raw QA LoRA | 后续必要时训练评测 | 交叉测试可选 | 两类输入各自适配后的系统差异 |

前两行优先，无需新训练。若要声称公平的 raw 系统上界，再补第三行；memory 训练的 decoder 读 raw 存在分布适配偏差。

必须同时报告 EM、F1、substring、输出长度，人工抽查分歧例，尤其 yes/no 与列举多个候选的输出。substring 不是绝对格式无关的正确率，+11.4 点也不能直接全部解释为证据读取改善。

输出逐例配对结果与 bridge/comparison 分层。dev 用于诊断；未使用的 test 保持锁定，方案确定后再做最终验证。

### P1：K=2 gold 文档 + 逐跳诊断（最高优先级机制实验）

对同一批可人工核验的 bridge 题，raw 与 memory 均测：

1. 原始多跳问题。
2. 第一跳子问题：找桥接实体。
3. 第二跳子问题：明确给正确桥接实体，问最终事实。
4. 原始问题 + 正确桥接实体提示。
5. 对应 K=10 条件，用于检查干扰影响。

建议增加混合输入：第一篇 raw + 第二篇 memory，以及第一篇 memory + 第二篇 raw。文档身份、顺序和来源编码保持可追溯，必要时双顺序检查。

**防泄漏：**子问题及桥接提示人工核验，不直接透露最终答案；提供 gold 中间实体属于 oracle 诊断，不计入部署主表。

| 结果模式 | 下一步解释 |
| --- | --- |
| memory 单跳也明显差 | 优先查事实保真度或解码能力，尚不能仅凭失败证明信息不存在 |
| 两跳分别可答，组合失败 | 在线连接/组合成为更强候选 |
| 给桥接实体后恢复 | 第一跳获取或跨文档连接值得定位 |
| K=2 接近 raw，K=10 差距扩大 | 干扰下选择、覆盖或利用问题 |
| 仅某篇换成 raw 即恢复 | 定位到相应跳的表示/读取瓶颈 |

重建实体召回只作辅助，不作信息存在与否的唯一判据。多个原因可以共存，不要求强行分成互斥类别。

### P2：上下文化的功能阻断（仅当该假设仍值得追）

先做推理诊断，保持非 memory 位置正常更新，memory 仍向后续位置提供 K/V：

- 正常。
- 阻断 memory 位置 attention 输出的残差写入。
- 阻断 memory 位置 MLP 输出的残差写入。
- 两种写入都阻断。

只干预真正 memory 位置，明确是否包含 SEP；维持 mask、位置、prompt 和生成设置一致。测 QA、答案 NLL 与逐跳能力。

- 阻断明显变差：原本看似小的更新有功能价值，“只读”说法不成立。
- 阻断近似无影响：支持当前配置对这些更新依赖较弱；不证明增强更新无用。
- 阻断属于人为分布改变，结合幅度/分层检查解释，不把任何掉分都称为纯机制证明。

### P3：按诊断结果选择解决方案

| 已获证据 | 优先方向 | 必须保留的对照 |
| --- | --- | --- |
| 单跳事实读取不足 | 降低压缩率、实体/关系保真监督、压缩器微调 | 相同 cache 大小/训练预算及读取器适配对照 |
| 单跳可读、组合失败 | 有逐跳监督的 query-conditioned readout，或 memory 后少量工作位置 | 强 P₁；等在线预算；无逐跳监督版本 |
| K=2 好、K=10 差 | 两篇支持文档覆盖、干扰鲁棒性、证据选择 | oracle 支持集与真实选择分开报告 |
| 适配后 raw–memory 差距已小 | 同质量下在线预算、端到端延迟、多查询复用收益 | 包含 query 编码/readout 成本的完整链路 |

不要求 memory 残差更新达到普通 token 数值。有效性的主标准是任务能力及可解释的失败恢复，不是几何外观更“像文本”。

## 5. 服务器回报格式与停止条件

下一份结果报告至少包含：

1. 精确 commit、训练/评测配置、样本 ID、checkpoint、prompt、截断、随机种子。
2. 已修正的统计与旧结论对应表。
3. 同口径 raw–memory 差距和逐例配对结果。
4. K=2/10、逐跳与桥接提示矩阵，附代表性失败例。
5. 哪些假设获得支持、哪些被削弱、哪些依旧无法区分。
6. 下一模块的一句话依据：“观察到 X；通过干预 Y 验证其影响；因此尝试 Z；成功标准是 W”。

停止条件：

- 未明确实际 QA 失败类型前，不启动一批新 readout 结构。
- 能量统计未更正、且未证明与任务相关前，不以“容量浪费已量化”为理由启动白化训练。
- P0/P1 已能排除方向时，不为追求完整机制图继续无目标扫描。
- 不从单一系统和有限干预写出“全量软压缩普遍不可行”的结论。

**最终目标：定位“哪条证据在什么环节用不了”，再决定修压缩、修读出还是修训练。**
