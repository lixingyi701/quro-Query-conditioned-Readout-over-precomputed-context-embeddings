## 5. 结论（探索性）

**S0X−S0 接近零（均值 +0.06 F1pp，bridge −0.02）**：不带 query 的跨文档 attention 几乎没有贡献，说明结构本身不能单独改善多文档聚合。

**SQX−SQ 的 bridge 方向一致但未过门槛（均值 +0.35，CI 跨零）**：和旧结果相比幅度缩水（旧 +0.73），顺序对齐是主要原因。

**交互项（bridge 均值 +0.36，CI 跨零）**：SQX 的 bridge 收益中有一部分来自 query 与跨文档结构的联合效应，不能完全归因于两者的独立加和。这是偏正的信号，但噪声仍大于信号。

**SQX−S0X（均值 +0.52，CI [−0.17, +1.19]）**：在有跨文档结构时 query 条件的贡献更清晰，两 seed 方向一致。这是全部八项对比里区间最靠近正轴的一项。

**当前结论**：普通全局文档级跨文档 attention 在顺序控制后没有稳定的、幅度明确的 QA 收益。想建立更强的证据，需要在另一多跳数据集（如 MuSiQue）上复现，或换更有针对性的结构（逐跳实体状态更新，参照 MDR/DecompRC）。
