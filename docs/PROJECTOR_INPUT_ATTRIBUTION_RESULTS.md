## 3. 结论

### 投影器收益完全来自方向，范数无贡献

`direction_only`（保留学到的方向、还原原始范数）在四个 run 里都与 `full`（完整投影器）相差不到 0.5 F1pp，而 `scale_only`（保留学到的范数、还原原始方向）与 `original`（原始缓存）的差值在四个 run 里的置信区间全部跨零，统计上与零无异。

换言之，**投影器约 47 F1pp 的收益几乎完全来自向量方向的改变，范数改变没有贡献。** 这与 pre-norm 架构（RMSNorm 把正比例缩放在第一层抵消）的理论预期一致。

### SQ 和 S0 的归因结构完全一致

四个 run（两种模型结构 × 两个 seed）的方向主导模式完全相同，说明约 47 F1pp 的收益是 SQ 和 S0 共有的投影器适配效果。SQ 相对 S0 的约 +0.37 F1 增量叠加在这个共有基础之上，不反映在范数/方向分解中。

### SQ 的 +0.37 F1 增量集中在 comparison 题

test 集全量结果（n=5405，两 seed 一致）：comparison 题 ΔF1 = +0.8 ~ +1.7，bridge 题 ΔF1 ≈ 0。query 条件读出对比较型问题有效，对桥接型问题无效。

### 对论文叙事的意义

投影器的价值在于改变 memory token 在 decoder 残差流中的方向，而不是把它们缩放到某个特定范数范围。后续新结构（query 引导证据读出）的核心目标应该是影响方向，不是范数。SQ 小幅领先 S0 的归因已确立——来自 comparison 题的 query 条件依赖。bridge 题无增益是当前方法的真实上限。

### 边界

`scale_only`/`direction_only` 是推理时混合输入，偏离训练分布；差值反映当前 checkpoint 的响应，不等于独立训练"只有范数/只有方向"模型的能力。上述结论适用于已训练 checkpoint 的分析，不可直接推广到新结构。
