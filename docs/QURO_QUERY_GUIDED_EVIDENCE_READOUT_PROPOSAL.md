## 1. 目标与已有起点

目标是在现有 QuRO 主线上完成一篇方法论文，优先改进正常 QA 中 query 的有效增量。事实翻转诊断降为可选分析，本提案不转向新的诊断论文或反事实训练路线。

保持现有约束：

- 文档由冻结的发布版 PISCO 离线压缩，缓存不随问题变化。
- K=10，每篇 m=8、d=4096，共 80 个 memory；在线模块逐篇计算，所有文档共享权重。
- 冻结 encoder、reader、既有 LoRA 与词嵌入；仅训练新条件读出分支。
- 正常 QA 的 decoder 保留正确问题，在线不读取原文，不使用 gold 支持标签。

依据的代码版本是 feat/pisco-joint-query-projector 的 102653d18f48d74603c3cf95e25c6af28a2c081a；上传前 main 为 98ab358a96203b53e7d764a3b4b908b8c8ff403f。

已有结果由项目记录提供，并非本提案重新运行：

- 独立训练的 SQ/S0 两 seed，全量内部 test 平均差约 +0.37 F1，逐题配对区间为 [-0.01, +0.74]。
- 支持分类（含直接监督最终 E）、FiLM、等容量加法与 G0 控制尚未建立新增 QA 优势。
- 旧 RQ 已试过“问题读取全部缓存，再转置分配写回”，匹配控制下边际近零。
- 早期小预算读出在去掉 decoder 明文问题的设置中已展示条件信息传递能力；这没有自动转化为正常 QA 优势。

主线记录：[20261006 projector 更新](QURO_PROJECTOR_RESEARCH_UPDATE_20261006.md)、[20261002 历史总结](QURO_RESEARCH_UPDATE_20261002.md)。

## 2. 核心设计假设

现有 SQ 大致为：

\[
E_i=Z_i+W_o\,\mathrm{GELU}(h_i(Z_i)+b_i(q,Z_i)).
\]

现有前置 attention 的 Q 来自 memory，K/V 来自问题；其输出首先是问题条件特征，再与文档分支经展平 MLP 融合。该结构确实使用文档信息，不能将它描述为“没有读取文档”。

本提案的假设是：共同训练时，通用适配可以解释大部分收益，条件分支缺少明确的内容读取目标。建议保留有效的静态适配基座，让新增分支专门学习“根据问题重组可读证据”。

这是待检验假设，不是已证明的失败根因。冻结静态基座会限制优化自由度，远程端需要判断这个约束是否值得采用。

## 3. 候选结构：静态适配＋条件 memory 读出残差

先复用对应 seed 已训练好的 S0：

\[
E_i^{(0)}=Z_i+f_0(Z_i).
\]

第一轮冻结 f0。由于它逐篇且不依赖 query，训练完成后的 E0 也可以离线预计算；是否另存这层缓存属于后续实现决策。

在每篇 8 个槽上增加以下读出：

\[
\begin{aligned}
U_i &= \mathrm{LN}(E_i^{(0)})W_z,\\
C_i &= \mathrm{CA}(Q=U_i,\ K/V=H_q),\\
R_i &= \mathrm{CA}(Q=U_i+C_i,\ K/V=U_i),\\
E_i &= E_i^{(0)}+\mathrm{FFN}(R_i)W_{\mathrm{out}}.
\end{aligned}
\]

采用行向量记法。初始设计宽度 r=256：U、C、R 的形状均为 8×256；Hq 是现有冻结 reader 的 question-only contextual states，通过 attention 内部 K/V 投影映射到 r；Wout 将 r 映射回 d。不同 attention 使用各自的投影参数。

第一步让各输出槽获得问题条件；第二步用这些条件去读取、组合同篇 memory 的值。第二次 attention 的 Value 来自文档表示，因此 query 影响的是 memory 内容如何组合。

初版只考虑一组这样的 block、8 个 head。最终输出线性层的 weight/bias 零初始化，起点严格为 E0；其他子层使用正常初始化，避免多重零门造成梯度阻断。保留原残差直通，不强制将最终 E 归一化。padding 文档和问题 token 必须正确 mask。

这些公式是结构草案，尚未固定完整 Transformer 子层、LayerNorm、内部残差与 FFN 细节；不应直接当作可执行配置。

与旧路线的关系：

| 路线 | 实质区别与重叠 |
| --- | --- |
| 当前 SQ | 新增条件化之后对 memory 的显式读出；保留已训练 S0 基座，新增分支不再承担全部共同适配 |
| 旧 RQ | 不采用“问题 token 读全池＋转置权重写回”；采用逐篇 memory 槽条件化后读同篇缓存，但仍属于已有条件读出机制的改进 |
| FiLM | 不是仅在隐藏通道上乘性调制；新增 attention 对 memory 值进行重组 |
| W | 不替换原有 80 槽证据通路，也不向 decoder 中间层插入新接口 |

**仅增加一次 attention 不足以建立新颖性。** 候选贡献要与下面的训练目标结合，并在正常 QA 上体现收益。

## 4. 训练目标：问题相关证据内容生成

保留正常 QA：

\[
\mathcal L_{\mathrm{QA}}
=-\log p_\theta(a\mid E(q,Z),q).
\]

同一个最终 E 另走辅助解码：

\[
\mathcal L_{\mathrm{evidence}}
=-\log p_\theta(s(q,D)\mid E(q,Z),p_{\mathrm{fixed}}).
\]

其中 s(q,D) 是与当前问题有关的短支持证据文本，pfixed 是所有样本统一的证据读取指令。**辅助 decoder 不直接接收当前问题；问题只进入投影器。** 梯度通过冻结 reader 传至最终 E 和新分支；reader 参数冻结不意味着该前向可以整体置于 no_grad。

首轮建议分别对 QA 与证据 CE 按有效目标 token 求均值，固定：

\[
\mathcal L=\mathcal L_{\mathrm{QA}}+0.1\mathcal L_{\mathrm{evidence}}.
\]

0.1 是起始设计值，不是验证过的最佳权重。证据无可用目标的样本仅保留 QA loss；没有证据目标不代表负例文档。

与旧监督的区别：

- 支持分类监督相关文档标签；这里要求最终 E 支持恢复具体的实体、关系和事实值。
- Direct-State 匹配教师完整 hidden states；这里监督证据文本，不要求整向量对齐。
- 不是重新运行普通答案 KD，也不需要改写事实。
- 去掉辅助路径的明文问题只是安排信息路径；不能声称这是项目首次让条件信息经过软表示。

teacher forcing 只用于目标评分；目标前缀可能降低恢复难度，不能据辅助 CE 降低就宣称 E 完整承载事实。Hq 也可能含参数知识，内容生成成功本身不是证据来源的因果证明。

部署时只运行正常 QA，不生成支持证据文本。训练增加一次辅助 reader 前向/输入梯度计算，实际显存与吞吐待测，不能宣称免费或训练耗时不变。

## 5. 数据可行性与边界

现有 prepare_hotpot_data.py 已保留 supporting_sentences，其中有 doc_rank、sent_id、text；现有支持可见性标注可以作为检查编码窗口的起点。

初版优先使用实际 PISCO 编码窗口内完整可见的支持句或经明确规则提取的短证据片段，保留实体、关系、事实值及必要桥接信息。不能要求从 Z 恢复 encoder 未读到的句子；若仅部分证据可见，应明确标记局部目标，不把它写成完整推理证据。

训练标签与原文仅用于离线构造目标，不进入新投影器，不用于在线 gold 文档筛选；辅助输入仍为全部 80 槽 E。

为减少“文档池固定输出某几句”的捷径，最好有一部分训练缓存同时对应不同问题和不同证据目标：

1. 先统计训练集中共享文档/文档池的现有多问覆盖，不能假定 Hotpot 天然是同池多问数据。
2. 若不足，可仅对训练文档构造小规模多问补充；保持事实不变，不做反事实改写。
3. 若新增数据，全部训练臂共享相同数据、清洗与采样规则，记录实际新增规模。
4. 补充问答不能取自验证/test 文档；新增多问数据按来源文档组拆分，必要时剔除与评估组的重叠。

现有字段是否足以构造合格短目标、完整可见样本占比以及多问覆盖率，需要远程端结合服务器数据审核。尚未给出经验证的数据规模或生成预算。

## 6. 候选最小训练对照

| 条件 | 条件输入 | 训练目标 | 目的 |
| --- | --- | --- | --- |
| A | 正常 query，新读出结构 | QA | 判断新结构在 QA-only 下的效果 |
| B：完整方法 | 正常 query，新读出结构 | QA＋证据生成 | 判断内容监督是否带来正常 QA 增益 |
| C | 固定、与问题无关的条件，同容量新读出结构 | QA＋证据生成 | 判断 B 的收益是否需要真实 query |

三臂从同一 seed 的 S0 起点开始，冻结相同静态基座。训练数据、QA 呈现次数、采样顺序、步数、学习率规则、验证与 checkpoint 选择保持一致。固定条件不能使用实际问句长度等侧信息；它应仍激活可训练的条件投影，以提供有效的容量控制。

主要证据是 B 对 C 及现有 S0/SQ 的正常 QA EM/F1；B 对 A 用于衡量加入辅助目标的效果。已有 S0/SQ 可作为历史参考，完整投稿比较仍须记录两阶段总训练成本和协议差异。

三臂不构成完整 2×2 因子实验，不能据此量化“query×辅助目标”的交互项；如果论文要主张这种交互，还需静态条件＋QA-only 的第四臂。

先用 dev 做开发判断，正式比较复核两 seed，test 不用于选择结构或权重。辅助证据生成成绩、错配 query 及输出变化只是补充；若只提升辅助任务，尚未完成所需 QA 方法改进。

## 7. 文献依据与候选论文贡献

以下是已检查原文的设计来源，具体迁移到 QuRO 是本提案推断：

| 工作 | 原文机制 | 迁移边界 |
| --- | --- | --- |
| [InstructBLIP](https://arxiv.org/html/2305.06500v2)，§2.3、§2.6、§3.2 | 指令与读出 query embeddings 交互，指导从冻结视觉特征中提取内容；训练 Q-Former，冻结两端 | 支持条件特征抽取原则，不保证 PISCO 的 8 个软槽具有相同可读性；不照搬其完整模型与训练规模 |
| [BLIP-2](https://arxiv.org/html/2301.12597v3)，§3.1–3.3 | 桥接模块分阶段训练，生成目标与 attention mask 控制信息经过读出表示 | 借鉴直接内容目标与信息路径，不把视觉预训练效果当作 QuRO 效果 |
| [xRAG](https://arxiv.org/html/2405.13792v1)，§3.2–3.4 | 冻结两端、训练 MLP 桥接；先恢复文档内容，再进行上下文任务训练 | 说明生成式桥接训练具有先例；本候选聚焦缓存后的问题相关证据适配，而不是宣称首次使用重建 |

候选故事：在可复用的静态软缓存上，先学习通用接口适配，再用问题条件 memory 读出与直接证据内容监督改善冻结生成器的 QA。

不将 attention、残差、Q-Former 或文本恢复本身称为新的技术。组合是否具有足够方法价值、新颖性以及 QA 收益均待审核/验证。若正常 QA 增量成立，再补第二数据集与在线成本；本提案不承诺 CCF-C 接收结果。
