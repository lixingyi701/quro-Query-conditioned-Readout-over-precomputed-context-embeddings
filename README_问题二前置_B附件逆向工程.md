# 问题二前置分析：B 附件逆向工程与 Q 口径反向修正

> 2026-09-23。脚本 `code_q1/q2_00_reverse_engineering.py` 可全部复现；表 `T8_reverse_engineering.csv`、图 `F8_reverse_engineering.png`。

## 一、三个逆向工程发现（按证据强度排序）

### 发现 1：B1 Pythia"训练日志"是公式生成的

对 B1 全部 1,176 行拟合 Chinchilla 形式，得

L = 1.6901 + 406.4·N^(-0.340) + 410.6·D^(-0.280)，RMSE = 0.00015。

真实训练轨迹不可能光滑到 1e-4 量级（学习率调度、数据顺序都会引入远大于此的波动）。**含义**：问题二对 B1 的"拟合"实质是恢复命题人的生成参数——E=1.690、α=0.34、β=0.28 就是标准答案本身；论文中拟合结果应与此完全一致，残差图会异常干净，需在论文中如实说明"B1 呈公式生成特征"（这也符合数据说明对半合成数据的定位）。

### 发现 2：B6/B7 的生成公式 = B1 基线 + 加性质量惩罚

Δ(N,D,Q) := L_NQ − L_B1(N,D) 对 (1−Q) 的线性 R² = 0.9974，且惩罚系数随 N 衰减：

**L(N,D,Q) ≈ 1.6901 + 406.4·N^(-0.34) + 410.6·D^(-0.28) + (1−Q)·(0.192 + 175.3·N^(-0.34)) + ε，ε~N(0, 0.051)**

三个结构性结论直接决定问题二的建模：

1. **命题人把 Q 做成加性惩罚，不是 D_eff 乘子**。我们对照拟合了五种形式：加性 (1-Q) RMSE=0.056 < 指数乘子 0.062 < B(Q) 线性 0.062 < 幂律乘子 D·Q^γ 0.072 ≈ 线性乘子 0.072。问题二的广义标度律主形式应选加性惩罚项（与数据生成机制一致），把文献偏好的 D_eff=D·f(Q) 乘子形式作为对照模型报告拟合劣势——这本身就是"模型选择有数据依据"的论证。
2. **质量惩罚与 N 交互：大模型对低质数据更鲁棒**（k(N) 从 0.54@70M 降到 0.24@12B，且 k1·N^-α 的形式与 A 项同指数）。这是问题二"质量×规模交互"的直接量化，也回应了问题一 λ 符号域间不一的现象——质量效应本来就是条件化的。
3. **人工噪声 σ≈0.05**：问题二拟合 B6/B7 时 RMSE 到 0.05 就到底了，不要过度调参去"击穿"噪声下限；置信区间用此 σ 传播。

### 发现 3：B8（large 表）与 B6/B7 不同源，禁止混合拟合

同 (N,D,Q) 网格点上两表 loss 相关 = −0.03（完全无关）；B8 内部 loss 随 Q **上升**（L(Q)/L(Q=1) ≈ 0.12+0.87Q，R²=0.99），还有 129/984 个点被截断在 0.5 下限。无论其 val_loss 语义是什么（疑似把质量增益直接当作损失、或 Q 定义相反），它与 B6/B7 的 Loss 方向相反。**处理规则**：问题二主拟合只用 B6/B7；B8 若用，只能在其内部做相对结构分析（如 extrapolated 与 calibrated 的一致性），并在论文中明确标注两表不可比、给出相关性≈0 的证据。这是数据审计的必写发现。

## 二、你们的猜想验证结果："问题2数据由问题1的Q计算"？

**结论：方向对了一半。** B6/B7 确实是"某个 Q 变量+标度律"生成的，但生成用的 Q 是 [0.1, 1.0] 的**均匀网格自由变量**，不是由 A 附件质量信号算出的具体数值——所以无法从 B 表"倒推出问题一 Q 的合成公式"（生成过程里没有那个公式）。能倒推的是更有用的东西：**Q 进入 Loss 的函数形式**（加性惩罚+N 交互）和**口径锚点**（Q=1 ⇔ Pythia 的 Pile 基线语料，因为 Δ(Q=1)≈0.004≈0，B6/B7 在 Q=1 处精确回到 B1）。

## 三、反向修正问题一：不改 Q 公式，补一个口径换算层

既然 B 表的 Q 是"以 Pile 语料为 1 的相对质量"，而问题一的 Q 是绝对合成分（17 域 ∈[0.355, 0.716]），正确的修正不是改问题一的评分公式（它有 A 附件的完整证据链），而是**在接口上补一列 B 口径的换算值**：

Q_B = Q_1 / Q_ref，其中 Q_ref = Q̄(p_pile) = Σ p_pile,d·Q̂_d = **0.5608**（Pile 训练配比均值加权）。

已写入 `interface/P1_Q_domain.csv` 新列 `Q_B_calibrated`：arxiv 1.28、stackexchange 1.05、pile_cc 0.99、dm_mathematics 0.63 等；Q_B(p*_等权)=0.988，Q_B(p*_cc)=0.977。**自洽性检验通过**：Pile 语料本身的 Q_B=1.000（构造保证），而 17 域 Q_B 分布在 [0.63, 1.28]，与 B 表 Q∈[0.1,1] 网格的高端区间重合——命题人设 Q 上限为 1 与"当前语料已接近其质量口径上界"的解读一致；Q_B>1 的域（arxiv 等）解释为"比 Pile 平均更优的语料"，问题三中"提质量"即把语料 Q̄ 从 1 向上推，成本函数 g(Q)−g(Q₀) 的 Q₀ 自然取 1（=Q_ref 归一后）。

**这个换算层要作为"假设 Q-锚定"写进论文问题二开头**，并做敏感性：Q_ref 取 Q̄(p_pile)=0.561（主）、token 加权全语料分（副）两种口径，报告下游弹性变化。

## 四、对问题二方案的直接影响（承接五天计划第二天）

1. 主模型形式由数据定：L = E + A·N^-α + B·D^-β + (1-Q)·(k₀+k₁·N^-α)·(配比修正)，其中配比修正项用问题一的 L_target(p)/L_target(p_pile) 或 (1-Q̄(p)) 惩罚，λ 域间符号差异提示配比项与质量项分开进。
2. D_eff 乘子形式（Muennighoff 风格）作为对照模型，报告其拟合 RMSE 劣势（0.072 vs 0.056），论证"本题数据支持加性形式"。
3. 弹性计算（ε_Q = ∂L/∂Q·Q/L）在加性形式下有解析式：ε_Q = −Q(k₀+k₁N^-α)/L，"Q 提高 0.1 等效多少 ΔN"可解析求解。
4. B8 只作 extrapolated/calibrated 内部一致性讨论；B2 (cerebras) 半合成（RMSE 0.011，比 B1 噪声大百倍，可当"伪观测"用于跨族检验）；scaling_baseline/published 是真实文献点，用于外部合理性检查（不同 tokenizer/验证集，只比趋势不比绝对值）。
